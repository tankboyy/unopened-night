# 열리지 않은 밤 (The Night That Never Opened)

2026년 10월 2일 고양종합운동장에서 열릴 예정이던 Post Malone 서울 공연은 8월 27일 연기됐고, 아직 새 날짜가 없습니다.
이 페이지는 그 밤이 원래대로 열렸다면 어땠을지 스크롤 한 장으로 다시 걷는 팬 제작 랜딩 페이지입니다.
Parallax 제1회 해커톤 「랜딩톤」 출품작입니다.

## 무엇을 하나요

- **스크롤 = 10월 2일 하루**: 티켓(16:00) → 입장(18:30) → 암전(19:58) → 스페셜 게스트(20:00) → 본공연(21:20) → 객석 조명(22:40)
- **스페셜 게스트 돈 톨리버(14곡) + 포스트 말론(22곡)**: 서울 공연 공지대로 20:00 게스트 무대(DJ 부스), 21:20 본공연(밴드).
  실제 2026 투어 세트리스트를 공식 YouTube 영상으로 무대 뒤 LED 벽 전체에 틀고, 노래에 맞춰 화면이 흘러갑니다.
  스크롤을 내리면 속도에 따라 빨리감기가 되고, 멈춘 자리부터 다시 재생됩니다.
- **3D 스타디움**(three.js): 미드필드까지 뻗은 런웨이, 밴드 6인, 1만여 명의 관객, 무빙 라이트·레이저·LED·얼굴 중계 화면
- **하이라이트 불꽃**: 곡마다 YouTube "가장 많이 다시 본 구간" 그래프에서 뽑은 하이라이트에 불꽃 분수·불꽃 폭포·폭죽
- **기타 부수기**: 물리엔진(cannon-es)으로 기타를 휘둘러 무대에 내리칩니다
- **WASD 이동**, 끌어서 둘러보기
- **반전**: 객석 조명이 켜지면 무대는 비어 있고, 연기 공지가 나옵니다. "나도 그날 밤 그 자리에 있었다" 티켓을 만들어 공유할 수 있습니다.

## 실행

```sh
pnpm install
pnpm dev      # 개발 서버
pnpm test     # 동선·타임라인·빨리감기·관객 배치 테스트
pnpm build    # 운영 빌드(dist/)
```
